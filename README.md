**NEXUS** — A smart design system showcase with component library, design tokens, and interactive UI patterns built with React + TypeScript + Vite.

## ✨ Features

- 🎨 Design system with tokens & components
- 🌙 Dark themed elegant UI
- ✨ Interactive component showcase
- 📱 Fully responsive layout
- ⚡ Vite for fast development & build
